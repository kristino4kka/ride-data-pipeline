# Ride Data Pipeline

Автоматизированный ETL-пайплайн для обработки данных о поездках.

## Цель проекта

Подготовить аналитическую витрину по способам оплаты поездок и автоматизировать регулярное обновление данных.

## Что делает проект

1. Проверяет появление исходного файла в S3.
2. Запускает PySpark-задачу.
3. Группирует поездки по способу оплаты.
4. Рассчитывает:
   - количество поездок;
   - среднюю стоимость поездки;
   - средний размер чаевых;
   - общую выручку.
5. Записывает результат в ClickHouse.

```text
ride-data-pipeline/

Используемые технологии
- Python
- Apache Spark
- PySpark
- Apache Airflow
- Yandex Data Proc
- S3
- ClickHouse
Результат
В результате формируется таблица taxi_payment_summary, которую можно использовать для финансовых отчётов и аналитических дашбордов.
Запуск
Для запуска необходимо настроить подключения к S3, Airflow, Yandex Data Proc и ClickHouse. Конфиденциальные данные — пароли, логины и ключи доступа — в репозитории не хранятся.
